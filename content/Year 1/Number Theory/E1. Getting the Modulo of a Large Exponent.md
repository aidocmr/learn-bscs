## Cyclic Patterns in Modulos

| $3^n$ |  $3^n \mod 3$ |
| :-: | :-: |
| 3 | 3 |
| 9 | 9 |
| 27 | 7 |
| 81 | 1 |
| 243 | 3 |
| 729 | 9 |
| 2187 | 7 |
| 6561 | 1 |
| 19683 | 3 |

You'll notice as $n$ increases, the first *(rightmost)* digit cycles every 4 units in $n$. The pattern here is $[3, 9, 7 ,1]$ then it repeats.

## Modulo Arithmetic

Using modulo arithmetic, you can simplify exponents pretty easily.

$$
\Large
\text{Find $8^{2026} \pmod{7}$}
\normalsize\\\ \\
8^1 \equiv 1 \pmod{7}\\
8^{2026} \equiv (8^{1})^{2026} \pmod{7}\\
(8^{1})^{2026} \equiv 1^{2026} \pmod{7}\\
1^{2026} \equiv 1 \pmod{7}\\
\therefore \fbox{$8^{2026} \equiv 1 \pmod{7}$}
$$
